# AutomateX360 websites

Two sales funnel sites, one folder each. Each folder is a complete project and
is deployed as its own Vercel project from this repo.

| Folder | Site | Vercel Root Directory |
| --- | --- | --- |
| [`studio/`](studio/) | Brand + Website Studio, custom websites from $2,000 (studio.automatex360.com) | `studio` |
| [`autopilot/`](autopilot/) | Website + Booking System, $449 a month (autopilot.automatex360.com) | `autopilot` |

Both use the same GoHighLevel calendar, Google Sheet and WhatsApp alerts. See
each folder's README for how to run, edit and deploy it.
